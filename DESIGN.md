# DESIGN.md — Swedish EL website

> Planning artifact for the public price-tracking site. Kept so later passes stay consistent.
> Stack: static site generated by `site/build_site.py` into `docs/` (GitHub Pages) + ECharts,
> GSAP + Lenis. Regenerated daily by `run_daily.sh`.

---

## Phase 0 — Brief

- **Subject:** Swedish electricity price tracker (`swedish-el-oss`). Spot price (Nord Pool,
  SEK/kWh) + the real consumer bill (spot + energy tax + grid fee + VAT) + an ML forecast for
  next day / next week / next month.
- **Audience:** Swedish households who want to see what electricity costs now, what it will
  cost, and when it is cheap to run the dishwasher or charge the car.
- **Job of the site:** (1) track spot + bill price, (2) show the forecast with honest
  uncertainty, (3) help plan day-to-day electricity use. Easy to read above all.
- **Assets:** real data only, from the local Postgres gold layer (`fact_daily`, `price_forecast`,
  `price_forecast_summary`, `driver_daily`). No stock imagery; the data visualisation IS the
  imagery. This is honest and on-concept.
- **Language:** English, with Swedish domain terms (SE1–SE4, spotpris) where natural.
  *Assumption: switch UI copy to Swedish for the real consumer audience later.*
- **Constraints:** $0 software, static on GitHub Pages, no backend; data refreshes daily via the
  Mac pipeline. Must work without JS (content is real HTML text; charts enhance).

**Reference:** the Metabase dashboard we built is the content source of truth — spot trend, bill
breakdown, forecast (spot + bill + p10–p90), horizon summary, zone comparison, drivers.

**Pick: A — "The honest line."** Highest total, and it foregrounds the forecast (the site's key
value) while enforcing easy reading: you always know real vs forecast at a glance. It survives to
the footer (every chart obeys solid=real / band=forecast) and the 404 (a line that runs out).

**Steal from B (detail only):** the sequential zone/price ramp (SE1 lightest/cheapest → SE4
darkest/dearest) as the site's magnitude colour logic — a double meaning (map + price level) that
answers the "colour that is easy to understand" ask.

**Steal from C (a section, not the concept):** the "plan your use" panel (cheapest hour, peak vs
off-peak) serves the "plan day-to-day use" job.

### Concept Card
- **Idea:** The site is one continuous, honest price line: solid where known, a soft band where forecast.
- **Metaphor:** electricity as a current flowing forward in time; the forecast is the current continuing into less-certain light.
- **Signature:** the hero line draws from recorded (solid, dark) into the forecast band (soft, widening p10–p90) across the horizon (day / week / month).
- **Emotion:** calm confidence: "I can see what is coming and can plan around it."
- **Motion verb:** draw like a current, settle like the line finding its level.
- **Screenshot:** the single line where solid historical price becomes the soft forecast band over the horizon.
- **Anchor:** Swedish spotpris is a traded price-over-time; forecasting is solid=known / band=uncertain (anchored to the Nordic current + SE1–SE4 so it stays Swedish).

## Phase 2 — Art direction system

**Archetype:** Swiss index × Tech precise. Cool Nordic ground, near-black ink, ONE signal accent
used sparingly for the live/forecast "current". Monochrome base; colour earns its place only in
the data.

**Palette (named roles):**
| role | hex | use |
|---|---|---|
| `ground` | `#EEF1F5` | page (cool off-white, Nordic light) |
| `surface` | `#FFFFFF` | cards / chart wells |
| `ink` | `#0C1217` | text + the solid (real) price line |
| `muted` | `#566172` | secondary text (AA on ground) |
| `line` | `#E2E7EE` | hairlines, axis |
| `accent` | `#FF5A25` | the current: live price + forecast p50 line (sparingly) |
| `accent-soft` | `rgba(255,90,37,0.16)` | forecast p10–p90 band |

Data colours (easy to read, consistent everywhere):
- **Real / actual:** `ink` (solid) — "solid = real".
- **Forecast p50:** `accent` (the one signal).
- **Forecast band p10–p90:** `accent-soft` (uncertainty).
- **Bill composition (spot, energy tax, grid fee, VAT):** spot = `accent` (the variable part),
  tax = `#3D6FA6`, grid fee = `#4E8C7A`, VAT = `#B9C2CE`. ≤4, harmonious, colourblind-safe.
- **Price level / zone ramp (cheap → dear):** `#2E8B6F` (cheap, cool) → `#E4A11B` (mid) →
  `#C0392B` (dear, warm). Diverging magnitude: cold cheap, hot dear.

**Type:** `Space Grotesk` (display, headings, big price numbers; tracking −0.02 to −0.04em,
leading 0.9–1.05) + `Inter` (body 16–18px / 1.5, UI, tabular-nums for data). Two families: one
neo-grotesk voice + a clean body. Numbers set in tabular figures; real quotes; non-breaking space
between number and unit.

**Grid & rhythm:** 12-col, max-width 1180px, gutter 24px. Generous whitespace. Section rhythm
varies (big hero → tight data → wide chart → detail). "Four corners" frame: name top-left, zone
nav top-right, source/updated bottom.

**Shape:** one radius rule, `12px` on cards/wells, `999px` on pills/chips. Hairline borders, no
heavy shadows (subtle lift only).

**Motion language:** one easing family `cubic-bezier(.22,.61,.36,1)` (ease-out). 200–600ms. The
motion verb = "draw like a current, settle into place". Charts draw their lines in; sections
reveal with a 20–40ms stagger and a small rise (transform/opacity only); the forecast band opens
widening toward the horizon. Idle: the live "now" dot pulses very slowly. Reduced-motion: all
content visible, no draws/pulses.

**Composition plan (ASCII, one layout family per section):**
```
[ four-corner frame:  "Swedish EL"            SE1 SE2 SE3 SE4 ]
HERO   huge now-price (spot + bill)  ·  one honest line drawing into the band
       ───────────────────────────────────────────────
       |######## solid price ==== forecast ▒▒▒▒▒▒ band →|
       ───────────────────────────────────────────────
HORIZON   three big cards:  NEXT DAY · NEXT WEEK · NEXT MONTH   (spot + bill, p10–p90)
TREND     wide chart: historical line + forecast continuation (the signature band)
BILL      stacked bar: what you pay (spot + tax + grid fee + VAT)
PLAN      cheapest hour · peak vs off-peak · cheapest days  (plan your use)
ZONES     SE1–SE4 compared, coded on the cheap→dear ramp (map + price)
FOOTER    sources (ENTSO-E, SCB, ECB, EIA, SMHI), method note, generated timestamp
```

## Data / viz decisions (from data-visualisation)

- Line over time for spot + bill trend; forecast as line + band (uncertainty shown, not hidden).
- Stacked bar for bill composition (parts sum to the whole = the bill).
- Bar for zone comparison + horizon summary; sorted deliberately.
- Titles state the takeaway ("Electricity is cheapest in the north"). One message per chart.
- Direct labels where ≤4 series; tabular numbers; consistent SEK/kWh everywhere.
